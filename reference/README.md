# Reference Material

Reference pages provide stack-specific technical standards for the on-ramp.
They are teaching material for the supported track, not standards for an
application shipped by this repository.

| Reference | Scope |
|---|---|
| [Python style guide](PYTHON_STYLEGUIDE.md) | Google-style docstrings, type hints, logging, imports, Polars handling, and manual review for Python examples. |

Additional tracks should add their own reference page alongside the existing
material rather than rewriting the Python standard.
