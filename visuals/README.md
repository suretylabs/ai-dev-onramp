# Visual Companion

These Mermaid diagrams support the procedural guides. They are not substitutes for observed output or the running state record.

## Reading these diagrams

Shape and line style carry meaning throughout this companion set:

- **Rectangle** — an action or step.
- **Diamond** — a real decision or gate with labeled branches (for example `"pass"` / `"fail"`).
- **Stadium (rounded pill)** — a milestone, state, or verified outcome.
- **Cylinder** — a durable stored artifact or reference document (a file, environment, or lock).
- **Solid arrow** — the required next step.
- **Dashed arrow** — an optional, conditional, or loop-back path.

Each diagram defines its own short color legend, just above the diagram, for the roles it actually uses.
