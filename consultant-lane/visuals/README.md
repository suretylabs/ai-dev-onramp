# Consultant Process-Capture Visuals

These Mermaid diagrams support the consultant-lane guides. They are not
substitutes for SME observation, sign-off, or the filled process-capture
artifact.

## Reading these diagrams

Shape and line style match the root visual companion:

- **Rectangle** — an action or step.
- **Diamond** — a real decision or gate with labeled branches.
- **Stadium (rounded pill)** — a milestone, state, or verified outcome.
- **Cylinder** — a durable stored artifact.
- **Solid arrow** — the required next step.
- **Dashed arrow** — an optional, conditional, or loop-back path.
